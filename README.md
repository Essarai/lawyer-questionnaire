# 律师内容获客画像问卷

解压后在项目目录运行：`python3 -m http.server 8765`，然后访问 http://127.0.0.1:8765 。需要 Python 3；端口被占用时可替换为其他端口。请通过 HTTP 服务访问，不要直接双击 index.html。

局域网启动：`python3 -m http.server 8766 --bind 0.0.0.0`，同一网络的其他设备通过运行电脑的局域网 IP 和端口访问。

本包包含当前完整原型的页面、脚本、样式、静态依赖及许可证。浏览器中填写的个人数据、上传文件和此前的设计交接截图不包含在系统包内。问卷与文件保存在各自浏览器中，不提供服务端同步。

案例材料：支持 .docx 和文字型 PDF。本地读取文字，按明确的标题或字段标签匹配回填；未匹配字段需人工补充。扫描件需要先 OCR。提取原文与填写内容保存在当前浏览器，文件二进制内容不保存。

自媒体账号授权：仅演示交互，二维码不连接真实平台。真实授权需接入平台授权服务。账号管理不在本页面提供。

简历导入：支持 .docx 和文字型 PDF，识别明确标签和常见教育、工作经历格式。自动补充空字段，不覆盖已有回答；不同值可核对后采用。

法律服务：一级业务领域下可选勾选二级领域，不勾选也可直接创建服务。核心字段为服务名称、目标客户、场景、客户需求、收费区间。
